## 🌟 Tentang Proyek

Repositori ini berisi kode sumber untuk website portfolio personal **Bagus Narendra Rizqi Ananto**. Website ini dirancang dan dibangun dari awal menggunakan teknologi **Pure Web (HTML, Vanilla CSS, dan Vanilla JavaScript)** tanpa framework berat, menghasilkan performa yang sangat cepat, ringan, dan aksesibel.

### Fitur Utama

1. **🎮 Interactive 3D Macropad Showcase (v1.1)**
   - Custom mechanical macropad 16-key (layout 4x4) dalam perspektif 3D isometrik dengan keycap solid berwarna cerah (*vibrant matte blocks*) dan logo vektor teknologi putih (*monochrome crisp vectors*).
   - Dilengkapi title timbul 3D *'SKILLS'* pada chassis keyboard mekanikal.
   - Respon hover dan sentuhan instan dengan efek audio switch mekanikal (*thock click*) menggunakan **Web Audio API** native tanpa dependensi eksternal (dilengkapi tombol toggle mute).
   - HUD interaktif yang menampilkan kategori skill, deskripsi teknis, dan tautan langsung ke bukti proyek nyata.

2. **📋 Detailed Grid Mode (Accessible Fallback)**
   - Mode alternatif terstruktur berdasarkan kategori (Frontend, Backend, Database, Data Management, Tools) yang ramah screen-reader dan ATS.

3. **💼 Selected Projects Showcase**
   - **Featured Project:** *Sistem Administrasi Pembayaran SMK* (Laravel, PHP, MySQL, Blade, Bootstrap) lengkap dengan galeri tangkapan layar, rincian fitur, arsitektur pengembangan, dan modal detail interaktif.
   - Filter proyek dinamis tanpa reload halaman (All, Fullstack, Backend, Frontend).
   - Lightbox image viewer dengan navigasi keyboard panah kiri/kanan dan tombol Escape.

4. **⏳ Experience, Organization & Education**
   - Timeline riwayat pengalaman kerja (Kerja Praktik, Freelance Programmer).
   - Riwayat kepemimpinan dan organisasi di Ikatan Mahasiswa Muhammadiyah (IMM).
   - Informasi pendidikan di Universitas Muhammadiyah Purwokerto (Teknik Informatika).

5. **🌓 Dark & Light Mode**
   - Penggantian tema gelap/terang yang halus dengan penyimpanan preferensi otomatis di `localStorage`.

6. **🌌 Adaptive Starfield Cosmic Background**
   - Background partikel kanvas ringan dengan mouse parallax halus yang otomatis pause saat tab tidak aktif (`document.hidden`) dan menghormati `prefers-reduced-motion`.

## 🚀 Menjalankan Secara Lokal

Anda dapat menjalankan website ini dengan web server lokal mana pun (Laragon, XAMPP, Live Server VS Code, dsb.):

### Menggunakan Python:
```bash
# Masuk ke direktori proyek
python -m http.server 8000
# Buka http://localhost:8000 di browser
```

### Menggunakan PHP:
```bash
php -S localhost:8000
# Buka http://localhost:8000 di browser
```

### Menggunakan Laragon / Apache:
Tempatkan folder proyek di dalam direktori `www` (misalnya `c:\laragon\www\PORTFOLIO`), lalu buka:
```
http://localhost/PORTFOLIO/
```
