# Portfolio - Bagus Narendra Rizqi Ananto

Website portfolio personal yang menampilkan profil, proyek, kemampuan teknis, pengalaman kerja, organisasi, dan riwayat pendidikan.

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

## Menjalankan Proyek

Website ini dibangun menggunakan static files dan dapat dibuka langsung melalui browser atau menggunakan server lokal.

### Python:
```bash
python -m http.server 8000
```

### PHP:
```bash
php -S localhost:8000
```

### Laragon / XAMPP:
Tempatkan folder proyek di dalam direktori `www` atau `htdocs`, lalu buka melalui browser:
```
http://localhost/PORTFOLIO/
```
