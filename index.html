About Me

Saya adalah mahasiswa Teknik Informatika di Universitas Muhammadiyah Purwokerto dengan latar belakang Rekayasa Perangkat Lunak dari SMK Negeri 1 Slawi.

Perjalanan saya dimulai dari jurusan RPL di SMK, di mana saya belajar dasar-dasar pemrograman dan pengembangan perangkat lunak. Selama magang, saya mendapatkan pengalaman di bidang data entry di OEMAH DIGITAL, yang membangun kemampuan saya dalam manajemen dan pengolahan data.

Saat ini, saya fokus mengembangkan kemampuan di bidang Fullstack Web Development, membangun aplikasi web menggunakan Laravel, PHP, MySQL, dan teknologi web modern. Salah satu project utama saya adalah Sistem Administrasi Pembayaran SMK yang dikembangkan sebagai bagian dari Kerja Praktik.

Di samping akademik, saya aktif berorganisasi di IMM, KPU Fakultas, dan Bawaslu Universitas yang membentuk kemampuan leadership, komunikasi, dan manajemen data.
